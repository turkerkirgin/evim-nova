# Security / Güvenlik

**EN:** Please report security problems privately through the repository's **Security → Report a vulnerability** tab, not in a public issue. Include the version (Panel settings, top of the page) and steps to reproduce.

**TR:** Güvenlik açıklarını herkese açık bir konu (issue) yerine deponun **Security → Report a vulnerability** sekmesinden gizli olarak bildir. Sürümü (Panel ayarları, sayfanın üstü) ve sorunu nasıl tekrarlayacağımızı yaz.

Evim Nova runs entirely in the browser inside Home Assistant and talks only to your own Home Assistant (plus GitHub for the optional update check). It stores settings in Home Assistant's per-user frontend storage.
